# SKILL: Mega-Pipeline de Engenharia Autônoma (2026)

## 1. Missão e Propósito
Orquestrar de ponta a ponta o ciclo completo de vida de uma missão de código em 1 único comando autônomo: Isolamento Git Worktree -> AST Skeletonizer -> LATS Tree Search -> Mutation Testing -> SMT Verifier -> Atomic Merge.

## 2. Princípios Operacionais
- Nenhuma alteração é aplicada diretamente na branch principal sem aprovação em todos os 6 estágios.
- Rollback determinístico instantâneo diante de qualquer quebra de critério de aceite.

## 3. Comandos Centrais
```bash
python super_cli.py auto-dev "<objetivo da tarefa>"
```
