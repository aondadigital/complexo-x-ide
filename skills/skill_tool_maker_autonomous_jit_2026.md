# SKILL: Tool-Maker Autonomous JIT Engine (2026)

## 1. Missão e Propósito
Permitir que o sistema projete, implemente, valide sintaticamente via AST, compile e registre no catálogo MCP novas ferramentas físicas em tempo de execução sem intervenção humana, habilitando a auto-expansão do arsenal.

## 2. Princípios Operacionais
- Toda ferramenta gerada deve possuir tipagem estrita e conformidade com a Lei Zero Ghost.
- Execução de testes de sanidade antes de disponibilizar a ferramenta no catálogo.

## 3. Comandos Centrais
```bash
python super_cli.py make-tool <nome_da_ferramenta> "<descricao>"
```
