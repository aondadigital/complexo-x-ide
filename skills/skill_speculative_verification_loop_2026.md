# SKILL: Speculative Verification Loop (2026)

## 1. Missão e Propósito
Validar e testar especulativamente em memória todo código produzido por agentes antes de realizar qualquer gravação em disco físico, eliminando I/O desnecessário e bloqueando arquivos corrompidos.

## 2. Princípios Operacionais
- Verificação instantânea de conformidade sintática e compilação para bytecode.
- Avaliação de complexidade e presença de tipagens/docstrings.

## 3. Comandos Centrais
```bash
python super_cli.py spec-verify
```
