# Skill: Tríade Operacional (Codex + Claude Code + Antigravity)

## Objetivo
Garantir o mais alto padrão de entrega do Antigravity, combinando a precisão cirúrgica do Codex, a velocidade direta do Claude Code e a robustez de testes/memória do Antigravity.

---

## Pilares de Atuação

### 1. Cirurgia Mínima (Codex)
- Identificar exatamente o ponto de alteração.
- Modificar apenas as linhas necessárias.
- Não reescrever arquivos funcionais nem injetar dependências não solicitadas.

### 2. Eficiência e Praticidade (Claude Code)
- Respostas enxutas e focadas na solução.
- Execução rápida de comandos de terminal, builds e testes.
- Apresentar a saída real dos testes sem suposições.

### 3. Validação Real e Memória (Antigravity)
- Testar e validar a alteração antes de finalizar.
- Usar navegador/ferramentas visuais quando envolver interface web.
- Salvar aprendizados sempre que houver correção.

---

## Checklist de Conclusão de Tarefa
- [ ] Alterei apenas o que foi pedido? (Sem código extra)
- [ ] O código existente foi preservado intacto?
- [ ] Executei o teste ou verifiquei a sintaxe/build?
- [ ] A resposta está direta, clara e comprovada?
