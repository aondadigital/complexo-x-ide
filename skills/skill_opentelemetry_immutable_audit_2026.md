# SKILL: OpenTelemetry (OTel) Immutable Audit Trail (2026)

## 1. Missão e Propósito
Garantir rastreabilidade, observabilidade e governança imutável de todas as decisões, tokens consumidos, custos em dólares e chamadas de ferramentas dos agentes via spans OpenTelemetry encadeados criptograficamente.

## 2. Princípios Operacionais
- Conformidade total com os padrões OpenTelemetry e W3C Trace Context.
- Encadeamento de hashes SHA-256 estilo Merkle Tree para impedir adulteração de registros.

## 3. Comandos Centrais
```bash
python super_cli.py otel-audit
```
