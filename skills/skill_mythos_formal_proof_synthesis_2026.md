# SKILL: Mythos SMT Formal Proof Synthesis (2026)

## 1. Missão e Propósito
Sintetizar e certificar código de software com garantias matemáticas formais de ausência de deadlocks, satisfação de invariantes de estado e terminação garantida via solucionador SMT e lógica de predicados.

## 2. Princípios Operacionais
- Todo código de missão crítica deve carregar um certificado criptográfico SHA-256 de prova formal.
- Prova de ausência de acessos fora de limites e invariantes invioladas.

## 3. Comandos Centrais
```bash
python super_cli.py mythos-prove
```
