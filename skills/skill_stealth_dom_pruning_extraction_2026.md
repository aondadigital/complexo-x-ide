# SKILL: Stealth DOM Pruning & Markdown Extraction (2026)

## 1. Missão e Propósito
Expurgar de forma cirúrgica até 95% do ruído em páginas web (scripts, estilos, anúncios, rastreadores, cabeçalhos de navegação e rodapés) para extrair Markdown semântico puro em menos de 30ms.

## 2. Princípios Operacionais
- Preservar apenas a estrutura do conteúdo (`h1`-`h6`, parágrafos, listas, tabelas, código e links úteis).
- Minimização massiva de tokens de contexto para consumo imediato por agentes de IA.

## 3. Comandos Centrais
```bash
python super_cli.py prune-html
```
