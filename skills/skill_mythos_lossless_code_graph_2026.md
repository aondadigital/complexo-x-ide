# SKILL: Mythos Lossless Code Graph Traversal (2026)

## 1. Missão e Propósito
Navegar e indexar bases de código massivas através de grafos simbólicos e indexação HNSW, recuperando árvores de dependência completas com 100% de fidelidade de ponteiros e zero perda de contexto.

## 2. Princípios Operacionais
- Indexação relacional de classes, métodos e funções em tempo $O(1)$.
- Minimização de tokens sem comprometer a integridade de referências cruzadas.

## 3. Comandos Centrais
```bash
python super_cli.py mythos-graph [diretorio]
```
