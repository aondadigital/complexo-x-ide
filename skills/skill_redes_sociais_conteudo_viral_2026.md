# Skill: Redes Sociais, Conteúdo Viral & Distribuição Omnichannel (2026)

Esta habilidade estabelece as técnicas de criação de conteúdo de alta retenção, roteirização para vídeos curtos (Reels, TikTok, Shorts), formatação omnichannel e análise de engajamento algorítmico.

---

## 1. A Estrutura de Retenção de Vídeos Curtos (0 a 60s)
1. **Gancho Visual & Verbal (0-3s):** Quebra de padrão que gera curiosidade irresistível ou expõe uma dor imediata. Sem introduções lentas.
2. **Loop Aberto (3-15s):** Promete uma revelação crucial até o fim do vídeo para garantir tempo de exibição (Watch Time > 80%).
3. **Entrega de Alto Valor (15-45s):** 3 passos práticos, demonstração visual em tela ou antes vs depois.
4. **Chamada de Engajamento (45-60s):** "Comente 'X' para receber o link completo no Direct" (ativa automações de DM) ou "Salve para consultar depois".

---

## 2. Princípios de Distribuição Omnichannel
* Um único conceito é desdobrado em formatos nativos para cada plataforma: Carrosséis para o Instagram, Artigos de Autoridade para o LinkedIn, Threads para o X/Twitter e Mensagens Diretas para o WhatsApp.
