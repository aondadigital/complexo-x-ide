# SKILL: Continuous Sentinel Watchdog 24/7 (2026)

## 1. Missão e Propósito
Auditar continuamente o workspace do Operador para garantir estrita obediência às leis constitucionais: Zero Ghost (ausência de arquivos vazios/stubs), integridade sintática AST e proteção contra vazamento de segredos.

## 2. Princípios Operacionais
- Detecção instantânea de qualquer violação antes de commits ou deploys.
- Monitoramento não intrusivo com baixo consumo de CPU.

## 3. Comandos Centrais
```bash
python super_cli.py watch
python super_cli.py watch --continuous
```
