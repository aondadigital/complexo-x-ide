# Skill: Verificador Zero-Ghost & Motor de Indexação de Memória

Ferramentas utilitárias locais para cumprimento estrito do Mandamento da Realidade (Zero Ghost / Zero Mocks) e recuperação ultra-rápida de memória de sessões passadas.

---

## 1. Verificador de Evidência (`verifier.py`)
Executa verificações determinísticas de integridade das bases de conhecimento, dependências e workspaces.

```bash
python "d:/ANTIGRAVITY - SUPER/BIBLIOTECA DE CONHECIMENTO/tools/verifier.py"
```

---

## 2. Motor de Indexação de Memória (`memory_indexer.py`)
Pesquisa por palavras-chave em todos os mais de 30 diretórios de sessões passadas do Obsidian e skills em milissegundos.

```bash
# Exemplo de busca:
python "d:/ANTIGRAVITY - SUPER/BIBLIOTECA DE CONHECIMENTO/tools/memory_indexer.py" "Evolution API"
python "d:/ANTIGRAVITY - SUPER/BIBLIOTECA DE CONHECIMENTO/tools/memory_indexer.py" "Whisper"
```
