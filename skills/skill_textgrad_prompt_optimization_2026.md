# SKILL: TextGrad Prompt Optimization & DSPy (2026)

## 1. Missão e Propósito
Refinar e otimizar autônoma e matematicamente os prompts, regras e personas do sistema a partir de logs de falha e feedback de testes, eliminando repetição de erros operacionais.

## 2. Princípios Operacionais
- Análise de perda textual (Loss) direcionando a injeção de guardrails cirúrgicos.
- Preservação da concisão e clareza das instruções.

## 3. Comandos Centrais
```bash
python super_cli.py textgrad --prompt "<prompt_base>" --error "<log_erro>"
```
