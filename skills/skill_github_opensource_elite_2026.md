# Skill: Engenharia Open-Source de Elite do GitHub (2026)

Esta habilidade estabelece as melhores práticas mundiais inspiradas nos projetos mais estrelados do GitHub: automação CI/CD, revisão de código por IA, shaders WebGL/GLSL, scraping stealth, síntese e visualização de áudio e governança de repositórios.

---

## 1. Padrões de Qualidade & Engenharia Aberta
1. **Documentação Visual de Alto Impacto (README Cinematográfico):** Badges padronizadas, demonstrações visuais em SVG/Canvas e arquitetura de sistema expressa em diagramas.
2. **Revisão Contínua de Pull Requests:** Verificação automatizada de diffs, complexidade de código e ausência de vulnerabilidades antes do merge.
3. **Versionamento Semântico e Changelog (SemVer):** Commits padronizados alimentam automaticamente a geração de releases e notas de atualização.
4. **Proteção Pré-Commit:** Nenhuma chave, credencial ou segredo passa para o histórico do Git.
5. **Shaders WebGL & Gráficos na GPU:** Utilização de shaders GLSL para experiências visuais fluidas a 60 FPS.
