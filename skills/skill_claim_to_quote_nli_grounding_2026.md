# SKILL: Claim-to-Quote NLI Grounding & Anti-Alucinação (2026)

## 1. Missão e Propósito
Auditar logicamente afirmações de pesquisa comparando cada frase gerada com a citação original da fonte via Inferência em Linguagem Natural (NLI), eliminando alucinações de dados, métricas e números inventados.

## 2. Princípios Operacionais
- Toda afirmação deve carregar evidência formal da fonte original.
- Detecção estrita de métricas não suportadas pela citação.

## 3. Comandos Centrais
```bash
python super_cli.py verify-quotes
```
