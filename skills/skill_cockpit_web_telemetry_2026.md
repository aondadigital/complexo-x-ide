# SKILL: Cockpit Web & Telemetria em Tempo Real (2026)

## 1. Missão e Propósito
Fornecer um painel de controle visual moderno (Glassmorphism, Bento Grid, Dark Mode HSL) para monitoramento em tempo real do ecossistema, pipelines, grafos de memória e telemetria.

## 2. Princípios Operacionais
- Servidor local ultraleve servindo a interface sem bloquear o terminal.
- Visualização de métricas de tokens economizados, VRAM PagedAttention e status de integridade.

## 3. Comandos Centrais
```bash
python super_cli.py cockpit
```
